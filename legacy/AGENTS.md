# 妖精的尾巴家族招募数据展示页 - 需求拆解文档

## 产品概述

- **产品类型**: 游戏家族招募数据展示官网（落地页）
- **场景类型**: <scene_type>prototype-app</scene_type>
- **目标用户**: 冒险岛游戏"妖精的尾巴"家族招募对象、现有家族成员、家族管理成员
- **核心价值**: 展示家族招募进度、成员构成、欢迎礼选择等数据，吸引新成员加入，体现家族活跃度

## 页面布局建议

- **布局模式**: 单页垂直滚动（自上而下叙事流），内容区居中最大宽度约束，各区块交替背景色营造节奏感
- **视觉重心**: Hero区（首屏视觉冲击）→ 席位统计/KPI（数据亮点）→ 成员列表（核心内容）→ 入群区（行动转化）
- **结果承载区**: 不适用（本页为纯展示型落地页，无用户输入/生成流程）
- **响应式策略**: 桌面端多列网格（成员卡片3-4列），平板端2列，移动端单列堆叠；导航栏移动端转为汉堡菜单

## 功能列表

### 顶部导航栏
- **页面目标**: 提供快速导航入口和品牌展示
- **功能点**:
  - **Logo展示**: 左侧显示"妖精的尾巴 FAIRY TAIL"品牌标识，点击滚动回顶部

  - **扫码入群按钮**: 右侧醒目CTA按钮，点击滚动到入群区
  - **滚动交互**: 页面向下滚动时导航栏背景从透明渐变到实色，增加阴影层次

### Hero区
- **页面目标**: 首屏视觉冲击，传达家族招募主题
- **功能点**:
  - **主副标题**: 大标题"妖精的尾巴 家族招募" + 副标题（冒险岛手游家族 · 暖心启程）

  - **枫叶主题背景**: 暖色调渐变背景 + 装饰性枫叶元素/光斑效果

### 席位统计
- **页面目标**: 直观展示家族席位情况
- **功能点**:

- **页面目标**: 展示三种欢迎礼及选择偏好
- **功能点**:
  - **三选一卡片**: 三张并排卡片分别展示皇家理发卷、皇家整容卷、58万游戏币
  - **选择人数**: 每张卡片底部显示选择该礼物的人数及占比进度条

  - **数据驱动**: 数值通过成员数据计算得出，确保一致性
  - **卡片动效**: 数字滚动计数动画，渐入呈现

### 职业分布
- **页面目标**: 展示家族五大职业构成
- **功能点**:
  - **雷达图**: 五维雷达图展示战士/飞侠/魔法师/弓箭手/海盗的人数分布（战士7、飞侠7、魔法师5、弓箭手2、海盗0）

  - **等级排序**: 每组内成员按等级降序排列
  - **成员卡片**: 每张卡片显示游戏ID、职业图标/标签、等级、在线时长标签、欢迎礼图标、YY状态标识（是/否）

### 需求洞察
- **页面目标**: 三栏展示多维数据洞察

  - **游戏风格分布**: 高效冲级15人、日常娱乐11人、养老休闲6人 — 进度条展示

// 成员数据接口
interface IMember {
  id: string;              // 唯一标识（可用游戏ID + 索引）

  characterClass: '战士' | '飞侠' | '魔法师' | '弓箭手' | '海盗';  // 职业

  gamePlans: string[];     // 游戏规划（多选）
  familyNeeds: string[];   // 家族想法（多选）
}

// KPI 数据
interface IKpiStats {
  totalMembers: number;    // 登记人数
  avgLevel: number;        // 平均等级
  classTypes: number;      // 职业种类
  yyActiveRate: number;    // YY活跃率（百分比）
  yyActiveCount: number;   // YY活跃人数
}

// 席位数据
interface ISeatStats {
  totalSeats: number;      // 总席位
  joined: number;          // 已加入
  remaining: number;       // 剩余
}

// 分布统计项
interface IDistributionItem {
  label: string;
  count: number;
}

# UI 设计指南

## 1. 设计推导依据

- **参考意图**: Mood Reference —— 参考飞书AI生成网页的现代精致、层次分明、信息清晰的气质，结合枫叶暖金主题重新塑造视觉语言
- **核心情绪 / 应用类型**: 冒险岛游戏家族招募数据展示页，温暖归属感 + 游戏仪式感，信息密集但节奏舒适
- **独特记忆点**: 酒红暖金枫叶主题贯穿全站，Hero区漂浮的半透明枫叶粒子，卡片底部渐变金箔描边，数据图表用枫叶红/琥珀金双色渐变填充

## 2. Art Direction

- **方向名**: 暖枫金韵
- **Design Style**: Soft Editorial + Warm Material —— 以编辑级排版呈现数据叙事，以奶油纸基底 + 酒红主色 + 暖金点缀营造家族仪式感
- **DNA 参数**: 圆角 soft (rounded-xl / rounded-2xl) / 阴影 layered (shadow-md + subtle glow) / 间距 spacious (gap-6 / p-8) / 字体方向 现代无衬线 + 衬线点缀 / 装饰手法 枫叶图形元素、金箔渐变描边、纸纹质感背景
- **应用类型**: Landing —— 纵向滚动叙事，数据区与内容区交替，节奏有张有弛

## 3. Color System

**色彩关系**: 酒红主色 + 暖金点缀 + 奶油纸白背景 + 深棕文字，整体暖调复古游戏家族氛围
**配色设计理由**: primary 酒红承担品牌识别与主行动，呼应枫叶主题与妖精的尾巴公会纹章气质；暖金 accent 用于高光、渐变、KPI数字和庆祝感元素；奶油色 bg 提供长时间阅读的舒适感，避免纯白刺眼
**主色推导**: 从枫叶自然色（酒红/橙红/暖金）提取主色，结合冒险岛复古游戏暖调配色记忆，选择深酒红作为 primary，暖琥珀金作为 accent，奶油米白作为基底
**使用比例**: 60% 奶油中性 / 30% 暖金与酒红辅助 / 10% 酒红 primary；主按钮与关键锚点用 primary，数据高亮与装饰用 accent，大面积留白用奶油色

| 角色 | CSS 变量 | Tailwind Class | HSL 值 | 设计说明 |
|---|---|---|---|---|
| bg | `--background` | `bg-background` | hsl(30 40% 96%) | 奶油米白纸色背景，微暖护眼 |
| card | `--card` | `bg-card` | hsl(0 0% 100%) | 纯白卡片，与奶油底形成层次 |
| text | `--foreground` | `text-foreground` | hsl(15 25% 15%) | 深棕红文字，比纯黑更暖 |
| textMuted | `--muted-foreground` | `text-muted-foreground` | hsl(20 15% 45%) | 暖灰棕次级文字 |
| primary | `--primary` | `bg-primary` / `text-primary` | hsl(355 65% 38%) | 深酒红，枫叶主色 |
| primaryForeground | `--primary-foreground` | `text-primary-foreground` | hsl(30 40% 96%) | 奶油白文字，高对比 |
| accent | `--accent` | `bg-accent` | hsl(38 85% 92%) | 暖金浅底，hover/选中态 |
| accentForeground | `--accent-foreground` | `text-accent-foreground` | hsl(30 70% 30%) | 深棕金文字 |
| border | `--border` | `border-border` | hsl(30 25% 88%) | 暖米色边框，柔和分隔 |

**语义色提示**: 成功 hsl(142 50% 45%) — bg hsl(142 60% 94%) / border hsl(142 45% 75%) / text hsl(142 55% 30%)；警告 hsl(38 90% 55%) — bg hsl(45 90% 94%) / border hsl(40 80% 70%) / text hsl(30 70% 30%)；错误 hsl(0 70% 55%) — bg hsl(0 75% 95%) / border hsl(0 60% 75%) / text hsl(0 65% 35%)。所有语义色饱和度与 primary 对齐（±15%），保持暖调统一，避免出现冷蓝绿破坏整体氛围。

## 4. 字体与节奏

- **font-display**: Noto Serif SC + Playfair Display —— 标题用衬线体营造公会仪式感和家族徽章气质，数字和英文用 Playfair Display 增加复古精致感
- **font-body**: Noto Sans SC —— 正文清晰可读，保证数据信息传达效率
- **字号**: H1 text-5xl md:text-6xl；H2 text-2xl md:text-3xl；body text-base；muted text-sm；大数字 text-4xl md:text-5xl。
- **圆角**: 大 —— 卡片 rounded-2xl，按钮 rounded-full，徽章/图标 rounded-xl，柔和圆润不失精致

## 5. 全局布局契约

- **Reference Layout Use**: 按需求结构推导，飞书AI风格参考影响信息密度、卡片层次和留白节奏
- **Page / Section Order**: 导航 → Hero → 席位统计 → 欢迎礼 → 招募概况KPI → 职业分布雷达图 → 在线活跃度 → 家族成员列表 → 需求洞察 → 入群区 → 页脚，严格对齐需求 10 块结构
- **Standard Content Zone**: `max-w-6xl` + `mx-auto`，Landing 级宽度适配数据展示与叙事节奏
- **Shell / Frame Alignment**: 顶部导航 sticky，内容容器与导航同宽对齐，Hero 与入群区为全宽例外
- **Padding & Rhythm**: `px-4 md:px-6 lg:px-8 py-12 md:py-20`，区块间 `gap-12 md:gap-16`，保持 8px 倍数节奏
- **Full-bleed Zones**: Hero 背景、入群区深色背景全宽，内部文字与按钮受 Standard Content Zone 约束
- **Local Narrowing**: 需求洞察三栏进度条区域保持全宽利用，成员卡片网格自适应
- **Overflow Strategy**: 成员卡片列表、职业分布区域使用响应式网格，移动端单列堆叠
- **Flexibility Boundary**: 允许移动端调整卡片列数、内边距和字号；不允许切换主色、圆角或阴影语言

## 6. 视觉与动效

- **装饰**: 枫叶图形元素 + 金箔渐变描边 + 微妙纸纹噪点
- **阴影/边界**: 中 —— 卡片 `shadow-lg` + 暖金内发光描边，hover 时 `shadow-xl` 微上浮
- **动效**: 精致 —— 卡片 hover 上移 4px + 阴影加深；数据数字 count-up 入场；枫叶粒子缓慢漂浮；进度条从左到右渐入；页面区块滚动淡入（fade-up）

## 7. 组件原则

- 按钮、卡片、菜单项必须有 Default / Hover / Active / Focus-visible / Disabled 状态
- Primary 按钮：酒红填充 + 奶油白文字 + 暖金微光；Outline 按钮：酒红边框 + 透明底 + hover 变酒红浅底；Ghost 按钮：透明底 + hover 暖金浅底
- 成员卡片：白底 + 顶部职业色条 + 底部金箔渐变细线 + hover 上浮动效
- KPI 数字使用衬线字体加大字号，配暖金色渐变下划线
- 图表（雷达图/进度条）使用酒红→暖金渐变色系，保持主题统一
- 空状态/加载状态延续枫叶与金箔装饰语言，不用默认骨架

## 8. Image Direction

- **Image Role**: Hero 背景图 + 入群区氛围图 + 欢迎礼产品图（理发卷/整容卷/游戏币）
- **Image Art Direction**: Hero 背景：秋日枫叶林特写，酒红与暖金色枫叶交错，柔光逆光，叶片有通透感，底部虚化适合叠文字，整体温暖治愈带游戏冒险感；欢迎礼图：三张精致的游戏道具图标风格插画，皇家理发卷/整容卷为卷轴造型配金边，58万游戏币为金币堆造型，统一手绘厚涂质感；入群区背景：深色枫叶纹理，低对比度，突出中央二维码
- **Image Prompt Keywords**: 枫叶林逆光、酒红暖金色调、柔光散景、游戏概念艺术、温暖冒险氛围、金箔边缘、手绘厚涂质感、卷轴道具设计、金币堆插画、深色枫叶纹理
- **Image Avoidance**: 避免卡通Q版画风、避免冷蓝绿色调、避免真人照片素材感、避免电商商品图平铺白底、避免无主题抽象渐变

## 9. Anti-patterns

- **Split personality**: 数据区用冷蓝、品牌区用酒红；全站共享暖枫金韵一套色板
- **Default SaaS drift**: 回到默认蓝按钮 + 灰白卡片；用酒红+暖金+奶油的主题系统取代默认 SaaS 风
- **Mono-hue tyranny**: 酒红铺满按钮、tab、图标、边框、链接；primary 只用于 CTA 和关键锚点，其余交给 accent 暖金与中性色
- **Invisible interaction**: 只做了 hover 动效，丢了 focus-visible；每个可交互元素都要有清晰的键盘焦点环（暖金外发光）
- **Card bloat**: 每张卡片都加大阴影+多边框+多重渐变导致视觉噪音；卡片用统一的轻阴影+底部金箔细线即可，层次靠间距而非装饰堆叠
- **Status color drift**: 成功/警告色饱和度远高于主色，显得突兀；语义色饱和度与 primary 对齐，色温保持暖调
